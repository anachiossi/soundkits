Sound kit

iPhone, iPad or Mac — Safari

  1. Open this link in Safari.
  2. Type the password. Tap Open.
  3. iPhone / iPad: tap Share (the square with the arrow ↑) → Add to Home Screen → Add.
    Mac: File → Add to Dock.
  4. Open it from the new icon. Type the password once more.

Android or PC — Chrome

  1. Open this link in Chrome.
  2. Type the password. Tap Open.
  3. Tap ⋮ (top right).
    Android: Add to Home screen → Add.
    PC: Cast, save and share → Install page as app.
  4. Open it from the new icon. Type the password once more.
